Linux essentials: building a secure foundation from scratch

2026-04-12 · 6 min read · Hardening · Beginner

Most machines get compromised through defaults nobody revisited. This walkthrough covers the three things worth fixing before anything else touches a fresh install: who can run what, what can reach the network, and what gets logged when something goes wrong.

1. User privilege management

Start from least privilege. Create a named account for daily use, keep root login disabled over SSH, and audit sudoers for anything broader than it needs to be.

$ sudo adduser analyst
$ sudo usermod -aG sudo analyst
$ sudo passwd -l root

2. Firewall configuration

A default-deny posture with explicit allows is worth the ten minutes it takes to set up. ufw is enough for most single-host workloads.

$ sudo ufw default deny incoming
$ sudo ufw allow OpenSSH
$ sudo ufw enable

3. Audit logging

You can't investigate what you didn't record. auditd with a small, deliberate rule set beats a verbose one nobody reads.

The goal isn't to log everything — it's to be able to answer "what happened" in under five minutes.
